1. Key Bindings                           *vimo_key_bindings*

### vimo Help
- [normal mode] `space then h` open vimo help in VIM

### Movement Key Bindings

- [normal mode] `space then f` quick jump to any words in the screen
- [normal mode] `space then r` rebuild ctags for current directory
- [normal mode] `ctrl and ]`  jump to definition, need to rebuild ctags first
- [normal mode] `ctrl and o` jump back to last cursor position
- [normal mode] `ctrl and i` jump back to next cursor position
- [normal mode] `space then space` jump to and jump back between the current editing file and the last edited file

### Selection Key Bindings

- [normal mode] `ctrl and n` press multiple times to select multiple current word and edit all of them at the same time

### Comment Key Bindings

- [visual mode] `g then c` toggle comment

### Complete Key Bindings

- [insert mode] `tab` auto complete with next candidate
- [insert mode] `shift and tab` auto complete with previous candidate

### Format/Alignment Key Bindings

- [normal/visual mode] `space then p` format the file (ALE: prettier for JS/TS/CSS/JSON/YAML/Markdown, gofmt for Go, rustfmt for Rust)
- [visual mode] `enter then =` align selected lines by =
- [visual mode] `enter then :` align selected lines by :

### Search & Navigations Bindings

- [normal mode] `space then b` fuzzy-find files (fzf), use `ctrl + j/k` to move between candidates
- [normal mode] `space then B` fuzzy-find open buffers
- [normal mode] `space then l` fuzzy-find lines in the current buffer
- [normal mode] `space then a` search text patterns in directories using Rg (ripgrep), the result will be shown in a [Quickfix](http://usevim.com/2012/08/24/vim101-quickfix/) window
- [normal mode] `space then k` search the word under the cursor (whole words only) in directories using Rg (ripgrep), the result will be shown in a [Quickfix](http://usevim.com/2012/08/24/vim101-quickfix/) window

### Diagnostics and Code Intelligence Bindings

- [normal mode] `space then d` show the full diagnostic under the cursor
- [normal mode] `space then g` go to the definition under the cursor
- [normal mode] `] then w` / `[ then w` next/previous diagnostic
- [insert mode] `tab` completes from the language server when one is running

### Undo, Tests and Discoverability

- [normal mode] `space then u` toggle the undo history tree
- [normal mode] `space then n` run the test nearest the cursor
- [normal mode] `space then N` run every test in the file
- [normal mode] `space then ?` show the available leader bindings

### Bracket Bindings

- [normal mode] `] or [ then q` next/previous quickfix entry
- [normal mode] `] or [ then b` next/previous buffer
- [normal mode] `] or [ then c` next/previous git hunk
- [normal mode] `y then o then an option letter` toggles that option, e.g. `yow` for wrap

### Windows Key Bindings

- [normal mode] `space then t` toggle directory tree, revealing the current file
- [normal mode] `space then T` toggle directory tree
- [normal mode] `space then s` split a new vertical window to the right
- [normal mode] `space then S` split a new horizontal window below
- [normal mode] `space then o` toggle window/fullscreen
- [normal mode] `space then w` shortcut for :w
- [normal mode] `space then W` shortcut for :w!
- [normal mode] `space then q` shortcut for :q
- [normal mode] `space then Q` shortcut for :q!
- [normal mode] `ctrl and h/j/k/l` move left/up/down/right among windows

### List Available Key Bindings

- `:map` all mode key mappings
- `:nmap` normal mode key mappings
- `:vmap` visual mode key mappings
- `:imap` insert mode key mappings
